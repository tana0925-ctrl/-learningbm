このフォルダは、キャラクターの絵（PNG・背景透過）を置く場所です。

■ ファイル名は「id.png」です。通し番号ではありません。
    タマゴン     → 1.png
    コケッコー   → 3.png
    コメットン   → 2117.png
  id は キャラ一覧の2列目の数字です。

■ 絵を足したら、同じフォルダの list.js にも id を足してください。
  list.js に書いていない id は、絵ではなく今までの絵文字が出ます。
  （こうしておくと、絵が無いキャラで通信の空振りが起きません）

■ id が重なっている2組について
    1003 スッポンキング … 絵は1枚でよい
    1011 アイディピン   … 絵は1枚でよい
  同じ id が2回登録されていますが、表示されるのは先に登録された方だけです。

■ 必要な枚数は 488 枚です（キャラは490体、うち2体は id の重なり）。
